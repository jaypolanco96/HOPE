# HOPE launcher icon

Original code-drawn H/skateboard badge matching the lime, pink, mint and
dark navy launcher palette. hope.svg is editable vector artwork. hope.png
is the 256 px review image; hope.ico contains 16, 20, 24, 32, 48, 64, 128,
and 256 px RGBA PNG entries. CreateIcon.ps1 regenerates PNG and ICO on
Windows without font dependencies. Both executable and window consume the
embedded icon; no external icon file is required at runtime.

Installed launcher 0.6.3 retains game 2.0.0.37-dev.g66ac4f3 (clothing hotfix).
The embedded executable icon was extracted and its colors checked. The
launcher passed 109 fixture checks. The installer verified seven payload
hashes and ten existing save/settings/original-file preservation hashes.
Older save/config copies and moved documentation were also verified.
